# Webpage audit: personal profile

This audit reviews `index.html`, `style.css`, and `script.js` against the requested profile-page requirements.

## Requirement checklist

| Requirement | Status | Notes |
| --- | --- | --- |
| HTML lives in `index.html` | Met | Markup, structure, and content are in this file only. |
| All styling lives in `style.css` | Met | Linked from the document head. No CSS in a `<style>` block. |
| No inline `style` attributes | Met | Presentation is class- and element-based. |
| Page title | Met | `<title>PLACEHOLDER Name \| Personal Profile</title>` |
| One main heading | Met | A single `<h1>`: `PLACEHOLDER Full Name` |
| About section | Met | `#about` with heading and two paragraphs |
| Skills section as a list | Met | `#skills` uses a `<ul>` of five items |
| Projects section with links | Met | `#projects` lists three linked projects |
| Unknown details marked PLACEHOLDER | Met | Name, role, location, skills, projects, email, and descriptions all include the word `PLACEHOLDER` |
| JavaScript in `script.js` | Met | Sets the footer year, logs leftover placeholders, and smooth-scrolls in-page nav |

## Structure

- Semantic landmarks: `header`, `nav`, `main`, `section`, `footer`
- Section headings use `h2` and are associated with `aria-labelledby`
- Navigation jumps to About, Skills, and Projects
- External project links currently point to `https://example.com/...` until real URLs replace the placeholders

## Accessibility and usability

- Language is set with `lang="en"`
- Viewport meta tag supports small screens
- Focus styles exist on links via `:focus-visible`
- Color contrast between text (`#1f2430`) and background (`#f4f1ea` / `#fffdf8`) is readable
- Footer email uses a `mailto:` link with a PLACEHOLDER address

## JavaScript behavior

- Inserts the current year into `#year`
- Counts visible PLACEHOLDER text nodes and prints them in the console so they are easy to find
- Smooth-scrolls primary navigation links that target page sections

## How to replace placeholders

Search the project for the word `PLACEHOLDER` and replace:

- Full name (heading, about copy, footer)
- Role / headline
- City and country
- About paragraphs
- Skill names
- Project titles, descriptions, and URLs
- Email address
- Document title

## Follow-up ideas (optional)

- Add a real photo and social links once details are known
- Host the site (GitHub Pages or similar) after placeholders are replaced
- Add a contact form only if a backend or form service is available
